# Post-Webinar Replay Asset Templates

## What This Is
Templates for generating branded PropFuel post-webinar replay assets in three sizes.
These are for **after** the webinar — promoting the recording. Pre-webinar assets are handled separately.

## Files to Upload to Project
1. `propfuel_logo.png` — PropFuel logo (pre-extracted, transparent background)
2. `template_yt_thumbnail_1280x720.py` — YouTube thumbnail
3. `template_website_banner_1200x400.py` — PropFuel website resources page
4. `template_propfuel_banner_2400x600.py` — PropFuel platform full-width banner
5. This README

## How to Use in Any Chat
Just say:
> "I need the 3 post-webinar assets for: [TITLE], [DATE], [SPEAKER]"

Or for Membership AI webinars (blue steel gradient on title):
> "I need the 3 post-webinar assets (Membership AI) for: [TITLE], [DATE], [SPEAKER]"

## Three Sizes

### YouTube Thumbnail (1280×720)
- Horizontal orange gradient top bar (14px)
- "WEBINAR REPLAY" header (28px/800 charcoal) + date/speaker line (19px/500 mid-grey)
- Warm divider line
- Title: 84px/800 charcoal (or blue steel gradient for Membership AI)
- "Watch Now" orange gradient pill button, left-aligned below title
- PropFuel logo top-right (92px height)
- No footer, paper texture background

### Website Banner (1200×400)
- Horizontal orange gradient top bar (8px)
- "WEBINAR REPLAY" header (14px/700) + date/speaker (12px/400)
- Divider line
- Title: 52px/800 charcoal
- "Watch Now" orange pill button below title
- Logo top-right (56px height)

### PropFuel Platform Banner (2400×600)
- Vertical orange gradient LEFT bar (14px, golden top → deep orange bottom)
- NO top bar on this format
- "WATCH THE RECORDING" header (34px/600 charcoal)
- Title: 110px/800 charcoal, vertically centered
- "Webinar Replay" orange pill button, bottom-right
- Logo top-right (150px height)

## Brand Constants
- Paper texture bg: #F4F1EA
- Charcoal text: #2F2F2F
- Orange gradient (buttons): left #F05A28 → right #FBC02D
- Mid grey: #6E6E6E
- Font: DM Sans (variable, downloaded at runtime)
- Membership AI blue steel: #1F3A51 → #4A7FA5 → #35607E
